# Submission checks

Official sources checked during development:

- [Challenge](https://dev.to/challenges/hacktoberfest-week2-2026-10-12)
- [Week 2 rules](https://dev.to/page/hacktoberfest-week2-2026-10-12-contest-rules)
- [General rules](https://dev.to/page/official-hackathon-rules)

Deadline: October 18, 2026, 11:59 PM PDT / October 19, 2026, 12:59 PM Asia/Dhaka. Repo began October 15, within the window. User confirmed personal eligibility and participation under the rules in chat; private personal details are not published here.

- New project; significant implementation built during the window.
- English article must follow the current official template, include `devchallenge` and `hf26challenge`, and use actual public repository/demo URLs.
- One project article only: inspect all authenticated user articles (including drafts) before creation, preserve its ID, inspect the saved draft, then publish the same ID. Do not create duplicate submissions.
- All paid-tool and live-model claims require actual evidence.
- Best Use of Render only after verified Render hosting.
- Best Use of Backboard only after an actual open-weight comparison through one Backboard key (or another qualifying use). A basic inference call alone does not meet the category wording checked here.
- No Tinker category, first-user claims, revenue, made-up feedback or guaranteed acceptance/prize.
- Credit models, licenses, hosted services, test tools and Codex assistance.
- Disclose every repository change after the official deadline in README.
- Final publication/deployment verification will be added once performed; this checklist is not proof of acceptance.
